# Регламент использования ИИ-ассистента PM («Практика-Трекер»)

**Назначение:** Стандартизация безопасного применения ИИ-ассистента `scripts/pm_weekly_assistant.py` для автоматической сборки еженедельных статус-отчетов и контроля рисков по возрасту задач (Age > 14 дней).  
**Ответственный:** Сәбитов Азамат (гр. АЖ-47, Solo PM & Developer, ФИТ ЕНУ им. Л.Н. Гумилева).

## 1. Инструкция по запуску и демонстрации

### Вариант А: Локальный запуск одной командой (для показа преподавателю)
```powershell
cd praktika-tracker
python scripts/pm_weekly_assistant.py
```
**Результат работы (за ~15 сек):**
1. Скрипт обращается к GitHub REST API (`api.github.com/repos/M10R7/praktika-tracker`), выгружает коммиты Спринта 2 и Спринта 3, прогоны CI/CD и рассчитывает возраст открытых задач (`age_days`).
2. Сохраняет эталонный слепок цифр в [`docs/reports/raw_github_facts.json`](../reports/raw_github_facts.json).
3. Очищает текст функцией `sanitize_text()` от любых email, телефонов и 12-значных ИИН/БИН.
4. Генерирует черновик отчета в [`docs/reports/weekly_status_sprint2_3.md`](../reports/weekly_status_sprint2_3.md).

### Вариант Б: Автоматический запуск по расписанию (GitHub Actions)
- Конфигурация: [`.github/workflows/weekly-status.yml`](../../.github/workflows/weekly-status.yml).
- Расписание: каждую пятницу в `10:00 UTC` (`15:00` Астана) либо вручную кнопкой **Run workflow (`workflow_dispatch`)**.
- Итоговый черновик и сырой JSON сохраняются в Artifacts прогона CI сроком на 30 дней.

## 3. Стоп-лист: данные, ЗАПРЕЩЕННЫЕ к передаче во внешние LLM

Согласно **Закону РК № 94-V «О персональных данных и их защите»** и внутреннему регламенту безопасности ЕНУ, категорически запрещено отправлять в облачные/сторонние модели:
1. **Персональные данные (ПДн) студентов и преподавателей:** ФИО студентов, 12-значные ИИН, номера телефонов, личные email-адреса, медицинские справки и сканы договоров.
2. **Данные баз практик под NDA / БИН:** закрытые реквизиты контрагентов, внутренние финансовые ставки, скан-документы с печатями.
3. **Секреты инфраструктуры:** `GH_TOKEN`, пароли PostgreSQL, строки подключения `DATABASE_URL`, приватные SSH-ключи VPS.
4. **Запрещенные к делегированию ИИ решения:** утверждение итоговых оценок, исключение студента из приказа деканата, принятие юридических формулировок договора № 107 без проверки юриста.

*(При необходимости обработки ПДн используется исключительно локальная модель Ollama на компьютере разработчика без доступа к внешней сети).*
