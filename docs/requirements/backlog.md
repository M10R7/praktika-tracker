## 2. Критерии приемки ключевых историй (BDD Scenarios)

### Сценарий US-06: Валидация БИН организации
```gherkin
Feature: Валидация БИН компании при подаче заявки

  Scenario: Ввод некорректного БИН
    Given студент находится в форме добавления новой компании
    When студент вводит БИН "12345678901" (11 цифр) или с неверным контрольным разрядом
    Then система отображает ошибку "Некорректный БИН. Номер должен состоять из 12 цифр с валидным контрольным разрядом"
    And кнопка "Сохранить и продолжить" заблокирована

  Scenario: Ввод корректного БИН
    Given студент находится в форме добавления новой компании
    When студент вводит валидный 12-значный БИН аккредитованного юрлица
    Then система валидирует БИН и активирует кнопку перехода к следующему шагу
```

### Сценарий US-09: Автогенерация трехстороннего договора в PDF
```gherkin
Feature: Автоматическая сборка PDF-договора

  Scenario: Успешная генерация документа
    Given заявка студента полностью заполнена валидными реквизитами
    When студент нажимает кнопку "Сформировать трехсторонний договор"
    Then серверный модуль генерирует файл PDF/A за время < 3.0 секунд
    And все реквизиты (Вуз, Студент, Предприятие) подставлены строго по утвержденной форме МОН РК
    And файл доступен для скачивания и сохранен в карточке заявки
```
