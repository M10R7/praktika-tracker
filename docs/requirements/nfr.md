# Спецификация нефункциональных требований (ISO/IEC 25010)

**Проект**: «Практика-Трекер»  
**Исполнитель**: Азамат (Solo PM & Developer)  
**Стандарт качества**: ISO/IEC 25010 Software Quality Model

---

## Реестр измеримых нефункциональных требований

| ID | Категория качества | Параметр требования | Измеримый критерий / Метрика | Метод верификации |
|---|---|---|---|---|
| **NFR-01** | Performance (Производительность) | Время отклика API | p95 времени ответа < 800 мс при постоянной нагрузке 200 одновременных пользователей (RPS ≥ 50). | Нагрузочное тестирование с помощью Locust / k6 |
| **NFR-02** | Performance (Производительность) | Время сборки PDF-договора | Генерация 3-страничного договора PDF/A не превышает 3.0 секунд при p90. | Бенчмарк фоновых задач ReportLab / WeasyPrint |
| **NFR-03** | Availability (Доступность) | Uptime сервиса | Доступность сервиса ≥ 99.5% в период активной кампании сбора (допустимый простой < 3.6 ч/мес). | Внешний мониторинг Uptime Kuma |
| **NFR-04** | Capacity (Масштабируемость) | Емкость хранилища и сессий | Поддержка хранения 20 000 архивных документов и до 500 параллельных сессий без падения сервиса. | Стресс-тест PostgreSQL и пула соединений PgBouncer |
| **NFR-05** | Security (Безопасность) | Аутентификация и шифрование | Хэширование паролей алгоритмом bcrypt (cost factor ≥ 12); обязательный протокол HTTPS (TLS 1.3); время жизни access токена 60 мин. | Аудит безопасности OWASP ZAP, проверка заголовков SSL Labs |
| **NFR-06** | Security (Безопасность) | Разграничение доступа (RBAC) | 100% изоляция прав: студент видит только свои заявки, координатор — студентов своей кафедры; 0% утечек данных. | Автоматизированные тесты pytest с матрицей ролей |
| **NFR-07** | Audit (Журналирование) | Аудит-лог изменений | Фиксация 100% операций смены статусов и экспорта документов в аудит-логе с user_id, IP-адресом и timestamp. | Проверка целостности журнала событий в PostgreSQL |
| **NFR-08** | Disaster Recovery (Надежность) | Восстановление после сбоев | RPO ≤ 24 часов (ежедневный автоматический дамп в S3); RTO ≤ 2 часов (полное развертывание из бэкапа по скрипту). | Учебное восстановление базы данных из дампа по секундомеру |
| **NFR-09** | Privacy (Защита данных) | Соответствие Закону РК № 94-V | Размещение серверов исключительно в ЦОД на территории РК (PS.kz, Алматы); согласие на сбор ПДн при регистрации. | Проверка геолокации IP-адреса и чек-лист соответствия ПДн |
| **NFR-10** | Interoperability (Совместимость) | Форматы генерируемых файлов | Генерация договоров строго в PDF/A (ISO 19005) и DOCX (ECMA-376); экспорт таблиц в UTF-8 CSV / XLSX. | Проверка валидатором форматов и открытие в MS Word / LibreOffice |
| **NFR-11** | Usability (Юзабилити) | Адаптивность и доступность | Корректное отображение на смартфонах (от 360px) и ПК; контрастность по WCAG 2.1 AA; поддержка казахского и русского языков. | Google Lighthouse (Accessibility > 90), тестирование DevTools |
| **NFR-12** | Maintainability (DevOps) | Контейнеризация и деплой | Развертывание приложения (FastAPI + PostgreSQL + Nginx) через Docker Compose одной командой за время < 5 минут. | Тестирование чистого запуска `docker compose up -d` в CI |
