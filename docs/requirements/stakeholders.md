## 2. Анализ «скрытых» стейкхолдеров

1. **Юристы вуза**: Требуют неизменяемости сгенерированного PDF-бланка. Студент не должен иметь возможности произвольно редактировать пункты договора после валидации.
2. **Служба ИБ**: Запрет на передачу паспортных данных и ИИН через публичные облачные API за пределами Республики Казахстан. Серверная часть и база данных PostgreSQL изолированы в казахстанском ЦОД.
3. **ИТ-эксплуатация**: Наличие четкого `runbook` по перезапуску контейнеров и ротации логов.
